版本說明與改版更新紀錄 (Changelog)

v1.3.1 (2026-08-12 最新版本)
  • PDF 預設檔名優化：將匯出 / 列印成 PDF 之預設檔名自動設定為 `[報價單號]_[裝修地址]_公司名稱.pdf`。
v1.3.0 (2026-08-12)
  • 整合「專案庫與紀錄」與「JSON 匯入」：將「匯入 JSON」與「專案庫與紀錄」按鈕與功能完美整合至同一專案管理中心。
  • 選擇 JSON 檔案路徑與載入：支援點擊「選擇 JSON 檔案載入」瀏覽並載入任意路徑下的 .json 報價單備份檔，亦支援拖曳檔案即刻載入。
  • 即時同步專案庫與共享檔：匯入之 JSON 資料將自動套用至編輯器，並同步紀錄至 LocalStorage 與 `data/quotations_db.json`。
  • 版號同步與介面修復：更新系統版本號至 v1.3.0，修復匯入彈出視窗閉合結構與優化按鈕樣式。
v1.2.0 (2026-08-11)
  • 新增 CSV 匯出功能：支援一鍵匯出 Excel UTF-8 BOM (.csv) 格式報價單，表格中文排版無亂碼。
  • 跨瀏覽器專案檔共享 (`data/quotations_db.json`)：支援同資料夾專案檔，不同瀏覽器 (Edge, Chrome, Firefox 等) 均可同步讀寫同一份報價單資料。
  • 工程與細項「項次序號 (1, 2, 3...)」：工程類別與細項表格全面增加項次編號，方便確認排序與總數量。
  • 開發版本號註記：新增 Header 與頁尾 Version Badge (v1.2.0) 及更新日誌視窗。
v1.1.0 (2026-08-10)
  • 工程分類新增【上移 ↑】與【下移 ↓】區塊排序按鈕。
  • 標頭整合常用工程種類下拉選單 (系統櫃、拆除、水電、泥作、木作等)。
  • 預設檢視切換為編輯模式，固定頂部 Header 高度為 60px。
  • 優化雙欄模式欄位寬度與項目 Drag & Drop 拖曳功能。
v1.0.0 (2026-08-10)
  • 裝修報價單管理系統首發版（完全參考《報價單_民權東路一段72號八樓.xlsx》）。
